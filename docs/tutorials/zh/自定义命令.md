<div align="center">
  <h1>🔧 自定义命令</h1>
  <p style="text-align: justify;">在 <strong>~/.gpumdkit.in</strong> 中定义 Bash 函数，就可以给 <code>gpumdkit.sh</code> 添加自己的快捷命令。</p>
</div>

## 工作原理

当 `gpumdkit.sh -<name>` 不是内置选项时，GPUMDkit 会加载 `~/.gpumdkit.in`，运行其中的 `custom_<name>` 函数，并把 `-<name>` 后面的所有参数传给它。内置选项总是优先，因此命名时不要与它们重复（可用 `gpumdkit.sh -h` 查看）。

用任意编辑器创建或修改该文件：

```bash
vi ~/.gpumdkit.in
```

## 基础示例

### 第一个命令

```bash
custom_hello() {
    echo "Hello, GPUMDkit user! This is a custom command."
    echo "Current GPUMDkit path: ${GPUMDkit_path}"
}
```

运行 `gpumdkit.sh -hello` 会输出：

```text
Hello, GPUMDkit user! This is a custom command.
Current GPUMDkit path: /home/yanzihan/software/GPUMDkit
```

### 使用参数

在函数中用 `$1`、`$2`……读取参数：

```bash
custom_greet() {
    echo "Hello, $1!"
}
```

运行 `gpumdkit.sh -greet Zihan` 会输出 `Hello, Zihan!`。如果要把全部参数转交给其他程序，请使用 `"$@"`，它会完整保留参数中的空格和特殊字符。

### 调用自己的脚本

```bash
custom_nepanalyse() {
    python ~/my_gpumd_tools/analyse_nep.py "$@"
}
```

运行 `gpumdkit.sh -nepanalyse`，后面可以跟上该脚本需要的参数。

## 组合 GPUMDkit 命令

### 批量绘图

```bash
custom_batch_plot() {
    for dir in "$@"; do
        (
            cd "$dir" || exit 1
            gpumdkit.sh -plt thermo save
            gpumdkit.sh -plt msd save
        ) || return 1
    done
}
```

用法：`gpumdkit.sh -batch_plot dir1 dir2 dir3`

### 检查训练集

```bash
custom_analyze_training() {
    xyz_file=$1
    echo "Analyzing $xyz_file..."
    gpumdkit.sh -range "$xyz_file" force
    gpumdkit.sh -min_dist_pbc "$xyz_file"
    gpumdkit.sh -analyze_comp "$xyz_file"
    echo "Analysis complete!"
}
```

用法：`gpumdkit.sh -analyze_training train.xyz`

### 准备训练数据

```bash
custom_prep_training() {
    gpumdkit.sh -out2xyz ./                                  # 输出 NEPdataset/train.xyz
    gpumdkit.sh -filter_value NEPdataset/train.xyz force 30   # 输出 filtered.xyz
    gpumdkit.sh -range filtered.xyz energy
}
```

用法：`gpumdkit.sh -prep_training`。力的阈值 `30` 只是示例，请根据你的体系选择。

## 完整示例

把下面两个函数放进 `~/.gpumdkit.in`：

```bash
custom_count() {
    # count the frames of every extxyz file given on the command line
    for f in "$@"; do
        printf '%s: %s frames\n' "$f" "$(grep -c '^Lattice' "$f")"
    done
}

custom_mindist() {
    # print the overall minimum distance of every file
    for f in "$@"; do
        printf '%s: ' "$f"
        gpumdkit.sh -min_dist_pbc "$f" 2>&1 | grep "Overall"
    done
}
```

然后在任意目录运行：

```bash
gpumdkit.sh -count dump.xyz sampled_structures.xyz
```

```text
dump.xyz: 100 frames
sampled_structures.xyz: 5 frames
```

`gpumdkit.sh -mindist dump.xyz` 的用法相同，会为每个文件打印 `Overall min_distance: … Å` 一行。函数里可以调用任何 GPUMDkit 选项，所以经常重复的项目专用检查可以收进一条命令。函数就是普通的 Bash：请给 `"$@"` 和 `"$f"` 加引号，这样带空格的文件名也能正常工作。

## 建议

- 名称要清楚：`custom_analyze_nep_training` 比 `custom_ant` 更容易维护。
- 缺少必需参数时打印用法提示。
- 处理前先检查输入文件是否存在。
