  <h1>📊 绘图脚本</h1>
  <p style="text-align: justify;">绘图模块包含一系列 Python 脚本，用于可视化 GPUMD、NEP 和 GPUMDkit 计算器产生的数据。所有图表均可交互显示或保存为高分辨率 PNG 文件。</p>

**脚本位置：** `Scripts/plt_scripts/`

## 快速入口

```bash
gpumdkit.sh -plt              # 显示所有绘图选项
gpumdkit.sh -plt <type>       # 生成指定图表
gpumdkit.sh -plt <type> save  # 保存为 PNG
gpumdkit.sh -plt -h           # 列出可用绘图类型
```

### 网页控制台中的点击绘图操作

运行 `gpumdkit.sh -server`，并在浏览器中打开一个工作目录。控制台只会在
检测到对应输入文件时显示绘图操作，并在该目录下调用相应的
`gpumdkit.sh -plt ... save` 命令。除已有操作外，目前还会识别：

| 当前目录中的输入 | 可用操作 |
|---|---|
| `force_train.out` | 力误差 |
| `rdf.out` | RDF |
| `xrd.out` | XRD |
| 至少两个 `<整数>K/xrd.out` 文件 | 按温度对比 XRD |
| `cohesive.out` | 内聚能 |
| `viscosity.out` | 黏度 |
| `phonon_NEP.dat` 和 `QPOINTS` | 声子能带 |

需要用户选择元素、温度、输入文件组合或其他科学参数的绘图，仍可在
terminal 中显式输入这些选项。

目录导航和文件管理说明见[远程 Web 控制台](远程网页控制台.md)。


## 从哪里开始

用 `gpumdkit.sh -plt -h` 查看绘图类型，并按对应小节的命令格式和 `save` 参数位置运行。

| 已有文件 | 优先使用 | 首先检查什么 |
|---|---|---|
| `loss.out`、`energy_train.out`、`force_train.out` | `gpumdkit.sh -plt train` | 损失曲线与能量/力 parity 图 |
| prediction 模式生成的 `energy_train.out`、`force_train.out` | `gpumdkit.sh -plt prediction` | `train.xyz` 中结构的 parity 结果 |
| `thermo.out` | `gpumdkit.sh -plt thermo` | 平衡过程和热力学量演化 |
| `gpumdkit.sh -calc msd` 生成的四列 `msd.out` | `gpumdkit.sh -plt msd` | 解读拟合前的扩散区间 |
| GPUMD `compute_msd` 单分组生成的七列 `msd.out` | `gpumdkit.sh -plt sdc` 或 `gpumdkit.sh -plt msd_sdc` | SDC 列和扩散区间 |
| GPUMD `compute_sdc` 生成的 `sdc.out` | `gpumdkit.sh -plt vac` | 速度自相关 |
| `rdf.out` | `gpumdkit.sh -plt rdf` | 所有可用的 RDF 数值列 |
| `xrd.out` | `gpumdkit.sh -plt xrd` | XRD 强度曲线 |

`compute_msd` 请求多个分组时会追加其他分组的数据。请检查分组布局，并在
适用时使用 `msd_all`，不要把每个 `msd.out` 都当作七列文件。

例如，保存训练结果图的命令是：

```bash
gpumdkit.sh -plt train save
```

## 完整示例：Thermo 输出

请在存放 `thermo.out` 的目录中运行绘图。本示例使用一次真实 NPT 运行（`npt_mttk`，900 K，50 万步，每 10 步写一行）的 `thermo.out`：共 18 列，包含温度、动能和势能、六个压力分量以及晶胞矢量的九个分量。

```bash
gpumdkit.sh -plt thermo save
```

## 绘图分类

- [NEP 训练与模型分析](NEP训练绘图.md) — NEP 训练和预测结果、电荷、描述符、dimer 曲线以及原子能量的绘图。
- [MD 与结构](MD与结构绘图.md) — MD 热力学输出和结构分析的绘图，包括极性材料的平面分布图。
- [扩散与离子输运](扩散绘图.md) — MSD、自扩散系数，以及扩散系数和离子电导率的 Arrhenius 拟合绘图。
- [热输运与声子](热输运与声子绘图.md) — EMD、NEMD、HNEMD 热输运、黏度、声子色散和 PDOS 的绘图。
