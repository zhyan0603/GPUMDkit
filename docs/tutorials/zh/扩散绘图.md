## 扩散和离子输运

### msd (`plt_msd.py`)

绘制各方向的均方位移 (MSD)。

**输入文件：** 前四列为时间和 `MSD_x/y/z` 的 `msd.out`。这包括
`gpumdkit.sh -calc msd` 生成的四列输出，以及 GPUMD `compute_msd` 输出的前四列。

图中的斜率使用 MSD 数据中间 40%–80% 的区间拟合。

```bash
gpumdkit.sh -plt msd
```

  <img src="../../Gallery/msd.png" alt="Mean square displacement" width="48%" />
</div>

---

### msd_all (`plt_msd_all.py`)

当 GPUMD 中使用 `all_groups` 时，分别绘制每种原子的 MSD。

**输入文件：** `msd.out`（需要使用 `all_groups` 选项计算）

**要求：** `run.in` 中的 `compute_msd` 命令必须使用 `all_groups`。多个分组时，
GPUMD 会追加分组数据；请检查其布局，不要假定文件具有单分组结果的七列。

```bash
gpumdkit.sh -plt msd_all msd.out Li P S
```

### msd_conv (`plt_msd_convergence_check.py`)

检查不同时间窗口下 MSD 计算的收敛性。

**输入文件：** `msd_step*.out`（需要在 `compute_msd` 中使用 `save_every` 选项）

**要求：** 在 `compute_msd` 命令中使用 `save_every`。

**用途：** 验证 MSD 是否已充分收敛以准确计算扩散系数。

```bash
gpumdkit.sh -plt msd_conv
```

<div align="center">
  <img src="../../Gallery/msd_convergence.png" alt="MSD convergence" width="48%" />
</div>

### sdc (`plt_sdc.py`)

绘制自扩散系数 (SDC) 随时间的变化。

**输入文件：** GPUMD `compute_msd` 生成的单分组七列 `msd.out`：时间、
`MSD_x/y/z` 和 `SDC_x/y/z`。`-calc msd` 生成的四列文件不能用于该绘图。

```bash
gpumdkit.sh -plt sdc
```

### msd_sdc (`plt_msd_sdc.py`)

并排绘制 MSD 和自扩散系数（SDC）。图中的斜率使用 MSD 数据中间 40%–80%
的区间拟合；右图插图展示 SDC 数据最后 80% 的部分，并叠加移动平均曲线。

**输入文件：** GPUMD `compute_msd` 生成的单分组七列 `msd.out`：时间、
`MSD_x/y/z` 和 `SDC_x/y/z`。`-calc msd` 生成的四列文件不能用于该绘图。

```bash
gpumdkit.sh -plt msd_sdc
```

### D (`plt_arrhenius_d.py`)

创建 Arrhenius 扩散系数图（log10 D vs 1000/T）。

**输入文件：** `*K/msd.out`（每个温度子目录下的 `msd.out`）

```bash
gpumdkit.sh -plt arrhenius_d
gpumdkit.sh -plt D             # 替代命令
```

**活化能输出格式：**

```text
Activation Energy: <Ea> eV, R2 = <R2>
```

### D_PT (`plt_arrhenius_d_PT.py`)

在用户指定的相变温度两侧绘制分段 Arrhenius 扩散系数图。相变温度点同时纳入
`LowT`（`T <= Tc`）和 `HighT`（`T >= Tc`）两段拟合。

**输入文件：** `*K/msd.out`

```bash
gpumdkit.sh -plt D_PT 380
gpumdkit.sh -plt D_PT 380 save
```

图例会直接标出两段活化能，例如 `HighT (xx eV)` 和 `LowT (xx eV)`。

### D_xyz (`plt_arrhenius_d_xyz.py`)

从各温度目录的 `msd.out` 计算 x/y/z 方向的扩散系数，绘制方向性 Arrhenius 图，
并对每个方向提取活化能。

**输入文件：** `*K/msd.out` 文件

```bash
gpumdkit.sh -plt D_xyz
```

---

!!! note "电导率图（sigma、sigma_PT、sigma_xyz）的前提假设"
    以下电导率图从首个温度的 `model.xyz` 合计 Li 和 Na 数量，按单价处理， 并对所有温度沿用相同离子数和扩胞倍数。适用于单一移动 Li 或 Na
    物种且 MSD 列与其对应的体系；其他物种、混合载流子或变组成体系需单独计算。脚本拟合 MSD 中间 40%–80% 的区间，并按
    Nernst–Einstein 关系外推 300 K 电导率。 使用结果前，应核验扩散区间与外推范围。

### sigma (`plt_arrhenius_sigma.py`)

创建 Arrhenius 离子电导率图（log10(σ·T) vs 1000/T）。

**输入文件：** 每个 `*K/` 目录中的 `thermo.out` 和 `msd.out`；首个温度目录中的
`model.xyz` 以及可选的 `run.in`

```bash
gpumdkit.sh -plt arrhenius_sigma
gpumdkit.sh -plt sigma         # 替代命令
```

### sigma_xyz (`plt_arrhenius_sigma_xyz.py`)

从各温度目录的 MSD 和热力学数据计算 x/y/z 方向的离子电导率，绘制方向性
Arrhenius 关系图，并用 Nernst-Einstein 关系提取每个方向的活化能。

**输入文件：** 每个 `*K/` 目录中的 `thermo.out` 和 `msd.out`；首个温度目录中的
`model.xyz`

```bash
gpumdkit.sh -plt sigma_xyz
```
