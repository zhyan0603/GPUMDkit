# GPUMDkit Agent Skill

GPUMDkit Agent Skill 是一套供 AI agent 使用的操作指引，涵盖 GPUMDkit 工具、
GPUMD 模拟和 NEP 训练与分析。安装后，你可以直接描述需求，让 agent 查阅
指引、选择合适的命令并协助完成任务。

使用前，请确认 GPUMDkit 已安装，并且 agent 所在环境可以运行 `gpumdkit.sh`；
也要允许 agent 在该环境中执行 shell 命令。请根据交流语言选择英文或中文版
skill；两者提供同一套 GPUMDkit 指引。

可以直接把下面这段话复制给 agent：

```text
请运行 `gpumdkit.sh -skill`，按照输出提示把相关 GPUMDkit skills 安装到当前
客户端的用户级全局 skills 目录，并确认安装后可以使用。
```

`gpumdkit.sh -skill` 会显示 skill 的位置和安装方法；实际安装由 agent 完成。

安装完成后，直接用自然语言描述任务即可。例如：

- “把这个 VASP 结构转换成 extxyz，并检查结果。”
- “检查我的 GPUMD 输出并绘制扩散结果。”

科学参数不明确时，agent 应先询问；耗时或昂贵的计算必须先得到你的确认。
