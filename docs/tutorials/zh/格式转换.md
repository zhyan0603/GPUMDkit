  <h1>🔄 格式转换</h1>
  <p style="text-align: justify;">格式转换模块用于在常见原子模拟文件格式之间转换，同时提供 group 标签、权重、帧提取等元数据处理功能。</p>
</div>

## 功能简介

本模块在计算材料科学中常用的结构和轨迹文件格式之间进行转换。支持 VASP、LAMMPS、CP2K、ABACUS、CIF、ASE 轨迹和 extxyz 格式。还提供添加 group 标签、权重、提取帧和扩胞等工具。

## 准备工作

**脚本位置：** `Scripts/format_conversion/`

请在希望存放结果的目录中运行 GPUMDkit：相对路径以当前目录为起点，而且即使输入文件在别处，大多数转换工具也会把结果写到当前目录。建议先用一小份数据试运行，以免覆盖已有结果。安装方法见[快速入门](快速入门.md)。

## 支持的格式

- **VASP**：`POSCAR`、`CONTCAR`、`OUTCAR`、`XDATCAR`
- **LAMMPS**：data 文件和 dump 轨迹
- **CP2K**：输出 log、坐标、力和晶胞文件
- **ABACUS**：SCF/MD 输出
- **CIF**：晶体结构文件
- **ASE trajectory**：`.traj`
- **DeepMD**：`npy` 数据集
- **extxyz**：GPUMD 和 NEP 常用的结构格式

## 看懂输入和输出文件名

第一次转换时，可以先使用只有两个参数的 POSCAR 路线，文件流向最直观：

```text
$ gpumdkit.sh -pos2exyz -h
 Usage: gpumdkit.sh -pos2exyz <POSCAR> <output.xyz>

 Arguments:
   POSCAR       One or more VASP POSCAR files (supports wildcards)
   output.xyz   Output extxyz file
```

`POSCAR` 是输入结构文件名，`output.xyz` 是命令创建的 extxyz 文件。通配符由 shell 展开；批量转换前应先确认实际匹配到的文件名。转换完成后可以先做一个轻量格式检查：

```bash
head -n 2 output.xyz
```

第一行是原子数，第二行包含晶胞和已有性质等 extxyz 元数据。

## 常见例子

### 将 DeepMD 数据集转换为 extxyz

使用 `-dp2xyz` 递归扫描 DeepMD 数据集目录，并写出 extxyz 文件：

```bash
gpumdkit.sh -dp2xyz database train.xyz
```

输入目录必须包含 `type.raw`、`type_map.raw` 和 `set.000/` 等 DeepMD 数据集文件。该命令依赖 `dpdata` 和 `ase`。

### 将带标签的 extxyz 转换为 DeepMD 数据集

给出输入文件和 DeepMD `type_map.raw` 的元素顺序：

```bash
gpumdkit.sh -xyz2dp train.xyz Li P S
```

不带参数运行 `gpumdkit.sh -xyz2dp` 时，会交互式询问这些信息。输入文件必须包含能量和力标签。输出写入当前目录下的 `deepmd_data/`。该命令依赖 `dpdata`。

### 转换 VASP 结果

**功能：** 在目录中搜索 VASP OUTCAR 文件，并将它们转换为单个 extxyz 文件，用于 NEP 训练或分析。

**命令行模式：**

```bash
gpumdkit.sh -out2xyz ./vasp_results/
```

上面是 shell 版本。也可以选择 Python 版本；同一批数据只需选择其中一种：

```bash
gpumdkit.sh -out2exyz ./vasp_results/
```

对于包含完整 VASP `BORN EFFECTIVE CHARGES` 数据块的 OUTCAR 文件，可以使用
带 BEC 的 shell 转换器：

```bash
gpumdkit.sh -out2xyz_bec ./vasp_results/
```

该入口为每个 OUTCAR 写出一个最终构型；当 BEC 数据块完整时，追加逐原子的
`bec:R:9` 属性。没有 BEC 数据块的 OUTCAR 仍会转换，但对应原子行不包含该属性，
同时会显示警告。

**交互模式：** 在格式转换菜单中选择 `101`，会看到：

```text
Input the directory containing OUTCARs
Example: ./
------------>>
```

**输出位置：** 两种命令都从指定的 `vasp_results/` 读取数据，但将结果写入**终端当前目录**：

| 入口 | 输出文件 |
|------|----------|
| `-out2xyz` 或菜单 `101` | `NEPdataset/train.xyz` |
| `-out2xyz_bec` | `NEPdataset/train.xyz` |
| `-out2exyz` | `train.xyz` |

!!! warning "重复转换前检查输出目录"
    shell 版本和 BEC shell 版本会删除并重建当前目录下已有的 `NEPdataset/`；Python 版本会覆盖当前目录下的 `train.xyz`。请先备份结果，或在新的工作目录中运行并指定输入目录的实际路径。

转换后可用 `head -n 2 NEPdataset/train.xyz`（shell/BEC 版本）或 `head -n 2 train.xyz`（Python 版本）查看原子数和 extxyz 元数据。文件生成成功不等于数据可直接用于训练，还需检查计算收敛情况、单位和标签。

### 添加 group 标签

**功能：** 为结构文件添加原子 group 标签。一些 GPUMD 相关流程需要 group 标签，例如特定元素的 MSD 或扩散性质计算。

**命令行模式：**

```bash
gpumdkit.sh -addgroup POSCAR Li Y Cl
```

该命令可以读取 ASE 支持的任意结构文件，输出 `model.xyz`；每个原子的 group 编号是其元素在列表中的位置（此例中 Li = 0、Y = 1、Cl = 2）。结构中的所有元素都必须列出。

**交互模式：** 在格式转换菜单中选择 `106`，会看到：

```text
Input <POSCAR> <element1> <element2> ...
Example: POSCAR Li Y Cl
------------>>
```

**输出：** 当前目录下的 `model.xyz`。

## 常用脚本说明

### POSCAR 转 extxyz

```bash
gpumdkit.sh -pos2exyz POSCAR model.xyz
```

适合把单个 VASP 结构转成 extxyz 文件。

交互模式关键词：`pos2exyz`

```text
Input <POSCAR> <output.xyz>
Example: POSCAR model.xyz
------------>>
```

### extxyz 转 POSCAR

```bash
gpumdkit.sh -exyz2pos structures.xyz
```

会将 extxyz 中所有帧转换成当前目录下的 `POSCAR_1.vasp`、`POSCAR_2.vasp`
等文件。程序按照输入轨迹中元素首次出现的顺序对每帧原子分组；例如
`Li La Zr O Li O La Zr O` 会使用 `Li La Zr O`。速度信息不会导出。

交互模式入口：`105`

```text
Input the name of extxyz
Example: ./train.xyz
------------>>
```

### LAMMPS dump 或 data 文件转 extxyz

```bash
gpumdkit.sh -lmp2exyz dump.lammpstrj Li Y Cl   # 文本 dump：转换所有帧
gpumdkit.sh -lmp2exyz model.data Li Y Cl       # data 文件：一个结构
```

元素顺序必须对应 LAMMPS 中的 atom type ID：type 1 是 Li、type 2 是 Y、type 3 是 Cl 时，输入 `Li Y Cl`。结果写入 `dump.xyz`；如果没有读到任何结构，则不会写出文件。文件类型会自动识别，压缩文件（`.gz`、`.bz2`、`.xz`）也可以直接使用。

对于 data 文件（`units metal`），会把盒子原点移到零点并把原子放回盒内，符合 GPUMD 的要求。data 文件中若有速度（换算为 Å/fs）、质量和电荷，也会一并保留；注意 GPUMD 会把 `model.xyz` 中的速度作为初始速度。不支持带 `element` 或 `mass` 列的 dump，请只输出 type 编号。

交互模式关键词：`lmp2exyz`

```text
Input <dump_or_data_file> <element1> <element2> ...
Example: dump.lammpstrj Li O
------------>>
```

### CIF 转换

```bash
gpumdkit.sh -cif2pos input.cif POSCAR.vasp
gpumdkit.sh -cif2exyz input.cif model.xyz
```

如果后续需要 VASP 计算，使用 `-cif2pos`；如果后续要进入 GPUMDkit 分析，使用 `-cif2exyz`。

### 添加权重

```bash
gpumdkit.sh -addweight train.xyz train_weighted.xyz 5
```

用于给训练集结构添加或修改权重。

### 扩胞

```bash
gpumdkit.sh -replicate POSCAR supercell.vasp 2 2 2
gpumdkit.sh -replicate POSCAR supercell.vasp 256
```

第一种按晶胞倍数扩胞，第二种按目标原子数自动选择扩胞方式。

### 提取单帧

```bash
gpumdkit.sh -get_frame dump.xyz 1000
```

把轨迹的第 `1000` 帧写入 `frame_1000.xyz`，帧编号从 `1` 开始。

### 拆分多帧 extxyz

`split_single_xyz.py` 将多帧 extxyz 文件拆分为单帧文件。

```bash
python "${GPUMDkit_path}/Scripts/format_conversion/split_single_xyz.py" dump.xyz
```

生成 `model_1.xyz`、`model_2.xyz`、... 等单帧文件。

### MTP 转换

将 MTP `.cfg` 格式转换为 extxyz：

```bash
gpumdkit.sh    # 选择：1) 格式转换 → 102
```

交互提示：

```text
Input <filename.cfg> <Symbol1 Symbol2 Symbol3 ...>
Example: train.cfg Pd Ag
------------>>
```

### ABACUS 转换

将 ABACUS 输出转换为 extxyz：

```bash
gpumdkit.sh    # 选择：1) 格式转换 → 104
```

菜单提供两个选项：

1. SCF 输出（`running_scf.log`）
2. MD 输出（`running_md.log`）

## 常见问题

| 问题 | 建议 |
|------|------|
| LAMMPS 转换后元素不对 | 检查 dump 文件后的元素顺序 |
| extxyz 元数据太多 | 使用 `-clean_xyz input.xyz clean.xyz` |
| 转换后的结构看起来偏移 | 检查源文件中的周期性边界条件/晶胞信息 |
| 提取帧不对 | 注意 `-get_frame` 的帧编号从 1 开始 |

## 说明

部分转换工具需要额外的 Python 包（例如 DeepMD 转换需要 `dpdata`），缺少时会在运行该功能时提示。
