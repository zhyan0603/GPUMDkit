  <h1>🔁 主动学习工作流</h1>
  <p style="text-align: justify;">用 GPUMDkit 完成一轮 NEP 数据迭代：MD 采样、筛选结构、DFT 标注，再重新训练。</p>
</div>

## 概览

一轮迭代分为五步：用 MD 生成候选结构、挑出有价值的结构、准备 DFT 计算、转换计算结果、更新数据集和模型。GPUMDkit 负责准备输入和分析输出；GPUMD、DFT 和 NEP 由你自己运行（或通过调度系统提交）。

## 开始之前

在新目录中工作，并保留上一版数据集和 `nep.txt`。下面几项会影响后续每一步，最好提前定下来：

| 项目 | 需要确定的内容 |
|---|---|
| 模型 | 从哪个 `nep.txt` 开始，以及它要覆盖哪些体系和条件 |
| MD 采样 | 起始结构和 GPUMD 模拟条件 |
| 筛选 | 距离和盒子尺寸限制、FPS 停止条件、保留的结构数量 |
| DFT | 程序、泛函、赝势、收敛设置和计算预算 |
| 数据集 | 新数据如何合并、加权，以及如何划分训练集和测试集 |
| 验收 | 精度和 MD 稳定性达到什么程度才算合格 |

## 便于扩展的目录结构

每一轮放在各自的目录中，不要覆盖前一轮的数据。下面是一种可行的布局（名称仅供参考）：

```text
project/
├── round_00/
│   ├── train.xyz          # 初始数据集
│   └── nep.txt            # 用它训练的模型
├── round_01/
│   ├── md/                # GPUMD 采样目录（菜单 302）
│   ├── candidates.xyz     # 经距离过滤后保留的帧
│   ├── selected.xyz       # 由 FPS 选出的帧（菜单 203）
│   ├── scf/               # DFT 目录（菜单 301）
│   ├── new_reference.xyz  # 转换后的 DFT 结果
│   ├── train.xyz          # 本轮合并后的数据集
│   └── nep.txt            # 本轮训练的模型
└── notes.md               # 每一轮的阈值、设置和结果
```

一轮中的命令按顺序如下，各步在下面的章节中详细说明：

| 步骤 | 命令 |
|---|---|
| 准备 MD 目录 | `gpumdkit.sh` → `3` → `302` |
| 过滤轨迹 | `gpumdkit.sh -min_dist_pbc dump.xyz`，再 `-filter_dist_pbc dump.xyz <minimum_distance>` |
| 选择结构 | `gpumdkit.sh` → `2` → `203` |
| 准备 DFT 输入 | `gpumdkit.sh` → `3` → `301` |
| 转换结果 | `gpumdkit.sh -out2xyz <scf_results_directory>` |
| 检查新标签 | `gpumdkit.sh -range <new_reference.xyz> force`、`-min_dist_pbc`、`-analyze_comp` |
| 检查新模型 | `gpumdkit.sh -plt train`、`gpumdkit.sh -plt prediction` |

表中的每个阈值和设置都需要**由你自己**决定，GPUMDkit 不会替你选择。

## 1. 生成候选结构

如果有多个起始结构或多套 `run.in`，先用功能 302 准备 GPUMD 批处理目录：

~~~bash
gpumdkit.sh  # 选择：3) Workflow -> 302
~~~

功能 302 只创建目录和符号链接。之后把 `nep.txt` 和每个结构对应的 `run_<index>.in` 放进生成的 `md/` 目录，确认每个目录都链接到正确的文件，再运行 GPUMD。

GPUMD 的部分输出文件是追加写入的，重新运行时请使用干净的目录，或先把旧输出归档。筛选之前，确认每个模拟都正常结束，温度、能量、压力和晶胞的变化符合预期，`dump.xyz` 完整且没有明显不合理的结构。

## 2. 选择候选结构

先检查原子间距，再进行过滤和最远点采样（FPS）：

~~~bash
gpumdkit.sh -min_dist_pbc dump.xyz                            # 只报告距离
gpumdkit.sh -filter_dist_pbc dump.xyz <minimum_distance>      # 输出 filtered_dump.xyz
gpumdkit.sh -filter_box filtered_dump.xyz <maximum_box_edge>  # 可选，输出 filtered_by_box.xyz
gpumdkit.sh  # 选择：2) Sample Structures -> 203) FPS by NepTrain
~~~

`-min_dist_pbc` 只报告距离，真正剔除结构的是 `-filter_dist_pbc`。只有体系需要限制盒子尺寸时才使用盒子过滤，此时把 `filtered_by_box.xyz` 交给功能 203。请记下所用的阈值、FPS 停止条件，以及选中的结构来自哪些帧。

### 另一种方式：委员会不确定度

如果你训练了一组 NEP 委员会模型，GPUMD 的 `active` 关键字会在 MD 过程中输出 `active.out` 和 `active.xyz`。随后可以用功能 205 按力偏差排序并限制数量。使用前请确认模型顺序、检查间隔、阈值、`top_n` 和 `min_deviation`。

## 3. 准备 DFT 计算

把选出的结构（`selected.xyz`）交给功能 301：

~~~bash
gpumdkit.sh  # 选择：3) Workflow -> 301 -> VASP 或 CP2K
~~~

VASP 分支会创建 `struct_fp/`、`fp/`、每个结构一个计算目录以及 `presub.sh`；之后把 `INCAR`、`POTCAR` 和 `KPOINTS` 放进 `fp/`。CP2K 分支（301 -> 2）会依次询问 extxyz 文件、输入模板和目录前缀。

提交前检查结构数量、原子和元素顺序、晶胞、DFT 输入以及作业脚本。GPUMDkit 不会提交作业。

## 4. 转换并检查参考数据

DFT 计算完成后进行转换。

VASP（在当前目录输出 `NEPdataset/train.xyz`）：

~~~bash
gpumdkit.sh -out2xyz <scf_results_directory>
~~~

如果 OUTCAR 中有完整的 `BORN EFFECTIVE CHARGES` 数据块，并且需要逐原子的 BEC 标签，请改用 `gpumdkit.sh -out2xyz_bec <scf_results_directory>`。

CP2K：在 CP2K 结果的根目录运行下面的命令。它会递归扫描 `.log` 文件及配套的 `.xyz`/`.inp`，输出 `cp2k_exyz.xyz`，处理记录写在 `Logfile.txt` 中：

~~~bash
gpumdkit.sh -cp2k2xyz
~~~

然后检查新文件（把 `<new_reference.xyz>` 换成上面实际输出的文件）：

~~~bash
gpumdkit.sh -range <new_reference.xyz> energy
gpumdkit.sh -range <new_reference.xyz> force
gpumdkit.sh -min_dist_pbc <new_reference.xyz>
gpumdkit.sh -analyze_comp <new_reference.xyz>
~~~

重点检查单位或标签是否正确、元素顺序是否符合预期、组成是否有缺失，以及重复结构、极端结构和失败的计算。原始 DFT 输出请保留。输出位置和文件何时会被覆盖，见[格式转换](格式转换.md)。

## 5. 更新数据集并重新训练

先备份上一版数据集，再合并新结构。如果相邻的轨迹帧同时出现在训练集和测试集中，测试误差会偏乐观；需要独立性时，请按轨迹或时间段划分。

修改 `nep.in`，训练 NEP，然后检查：

- 训练和测试损失；
- 能量、力和维里/应力的 parity 图（`gpumdkit.sh -plt train`、`-plt test`）；
- 按元素、组成、相和结构类型划分的误差；
- 异常点、短程行为，以及目标条件下的 MD 稳定性。

总体 RMSE 低并不代表模型已经可用。达到验收标准后，再用新模型进行下一轮 MD。

## 做好记录

每一轮都保留模型和数据集版本、所用命令和阈值、被剔除的结构以及验证结果。如果缺少输出或验证问题尚未解决，请先排查，不要进入下一轮。
