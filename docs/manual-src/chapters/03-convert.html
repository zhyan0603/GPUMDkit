把 DFT 与 MD 的输出转换为 extxyz，并整理成适合训练的形式。

Detailed pages详细页面Format conversion格式转换

GPUMDkit converts between the formats used in computational materials science and the extended XYZ (extxyz) files used by GPUMD and NEP. Run it in the directory where you want the results: most converters write into the current directory, even when the input is elsewhere.

GPUMDkit 在计算材料学常用格式与 GPUMD/NEP 使用的扩展 XYZ（extxyz）之间转换。请在希望保存结果的目录中运行：多数转换器即使输入文件在别处，也会把结果写到当前目录。

Anatomy of an extxyz fileextxyz 文件长什么样

train.xyz — illustrative values, 2 atoms示意数值，2 个原子
2
Lattice="5.43 0.0 0.0 0.0 5.43 0.0 0.0 0.0 5.43" Properties=species:S:1:pos:R:3:forces:R:3 energy=-10.52 virial="-0.21 0.0 0.0 0.0 -0.21 0.0 0.0 0.0 -0.21" pbc="T T T"
Si  0.00  0.00  0.00   0.012 -0.020  0.003
Si  1.36  1.36  1.36  -0.012  0.020 -0.003
  1. Atom count of this frame; a file stacks many frames.
  2. Lattice: nine numbers (three cell vectors, row-major, in Å).
  3. Properties declares the atom columns: species, position, force.
  4. Frame labels: total energy and virial (eV) from the reference calculation.
  5. One line per atom: element, position (Å), force (eV/Å).
  1. 原子数：当前帧的原子个数，一个文件可以串联很多帧。
  2. Lattice：9 个数（三个晶格矢量，按行排列，单位 Å）。
  3. Properties 声明每个原子行包含哪些列：元素、坐标、力。
  4. 帧级标签：参考计算得到的总能量和维里（eV）。
  5. 每个原子一行：元素、坐标（Å）、力（eV/Å）。
