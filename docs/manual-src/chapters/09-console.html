Remote web console远程网页控制台

Watch training and MD runs, and make figures, from your own browser.

在自己的浏览器里查看训练与 MD 运行，并一键出图。

Detailed pages详细页面Remote web console远程网页控制台

gpumdkit.sh -server starts a browser-based console rooted at the directory you launched it from. The browser shows files that stay on the remote machine, so you can inspect runs, trigger plots and do small file operations without copying the whole project.

gpumdkit.sh -server 会以启动时所在的目录为根，开启一个基于浏览器的控制台。浏览器显示的文件始终留在远程机器上，因此无需拷贝整个项目，就能查看计算、触发绘图并做简单的文件操作。

Connect in three steps三步连接

Start the server on the remote host在远程主机上启动服务

remote terminal — keep it open
ssh <user>@<host>
conda activate gpumdkit
cd /path/to/working-directory
gpumdkit.sh -server

Open an SSH tunnel from your workstation在本地工作站建立 SSH 隧道

local terminal — keep it running
ssh -N -L 8888:127.0.0.1:8888 <user>@<host>

Open it in your local browser在本地浏览器中打开

address
http://127.0.0.1:8888

If port 8888 is busy locally, forward another one (-L 8890:127.0.0.1:8888, then open port 8890). If it is busy on the remote host, start the server on another port (gpumdkit.sh -server 9000) and forward that one.

如果本地 8888 端口被占用，可转发到其他端口（-L 8890:127.0.0.1:8888，然后访问 8890）。如果远程 8888 被占用，则用其他端口启动服务（gpumdkit.sh -server 9000）并转发该端口。

Server options and safety服务选项与安全

syntax
gpumdkit.sh -server [port] [-b <address>] [-pw <password>]
gpumdkit.sh -server -h
Option选项Default默认值Meaning含义
port8888Port of the web serverWeb 服务端口
-b <address>127.0.0.1Network address to listen on监听的网络地址
-pw <password>optional on loopback回环地址下可选Login password; required for any other address登录密码；监听其他地址时必须设置
!
Keep the default loopback address and use an SSH tunnel. Binding to another address such as 0.0.0.0 requires a password and the server does not use HTTPS. The terminal drawer is not restricted to the browsing root. Keep passwords out of shared scripts and shell history.
请保持默认的回环地址，并通过 SSH 隧道访问。绑定到 0.0.0.0 等其他地址时必须设置密码，且服务不使用 HTTPS。终端抽屉不受浏览根目录限制。请勿把密码写进共享脚本或 shell 历史。
Symptom现象Check排查
Browser cannot connect浏览器无法连接Both the remote server and the local tunnel must still be running, with matching ports.远程服务和本地隧道必须仍在运行，且端口一致。
The wrong files appear显示的文件不对The root is the directory where -server started. Restart it from the intended directory.根目录就是启动 -server 的目录，请在目标目录中重新启动。
Plot actions fail绘图操作失败Start the server from the environment that has GPUMDkit and the plot dependencies.请在装有 GPUMDkit 及绘图依赖的环境中启动服务。
Progress does not change进度不变It only changes when the output files receive new records; it is not a scheduler monitor.只有输出文件写入新记录时才会变化，它并非作业调度监控。
