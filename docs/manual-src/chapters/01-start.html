Getting started快速入门

Install, verify, and run your first command in about two minutes.

两分钟内完成安装、验证，并跑通第一条命令。

Detailed pages详细页面Quick start快速入门

1Install安装

$conda create -n gpumdkit -c gpumdkit -c conda-forge gpumdkit

Conda is the recommended route: it installs GPUMDkit with its standard dependencies, with no repository clone or environment variables. Then conda activate gpumdkit. Choose source if you want to read or modify the code — the installer writes GPUMDkit_path and PATH to your ~/.zshrc or ~/.bashrc after backing it up.

推荐使用 Conda：它会连同标准依赖一起安装 GPUMDkit，无需克隆仓库或配置环境变量，安装后执行 conda activate gpumdkit 即可。如果想阅读或修改代码，请选择 source：安装脚本会先备份 ~/.zshrc 或 ~/.bashrc，再写入 GPUMDkit_path 和 PATH。

2Check that it works检查安装

gpumdkit.sh -h        # list every option
gpumdkit.sh -doctor   # check the Python environment
✓
MISS for an optional package is not an error. -doctor reports common and optional packages; install an optional one only when you need the feature that uses it, e.g. pip install neptrain calorine.
可选包显示 MISS 并不是错误。-doctor 会报告常用和可选的 Python 包；只有在需要对应功能时才安装，例如 pip install neptrain calorine。

3Your first conversion第一次转换

Run this in a new directory so no existing file is overwritten. It converts a one-atom silicon POSCAR to extended XYZ, the training-data format of NEP.

请在一个新目录中运行，以免覆盖已有文件。下面把一个单原子硅的 POSCAR 转换为 NEP 使用的扩展 XYZ 训练数据格式。

input
mkdir gpumdkit-first-check && cd gpumdkit-first-check
cat > POSCAR << 'EOF'
Si
1.0
0 2.715 2.715
2.715 0 2.715
2.715 2.715 0
Si
1
direct
0 0 0
EOF
gpumdkit.sh -pos2exyz POSCAR model.xyz
model.xyz
Conversion completed, structures saved to model.xyz

1

Si       0.00000000       0.00000000       0.00000000

4Two ways to work两种使用方式

Every tool is reachable both ways. Use the menu to explore; use options in scripts and batch jobs.

所有工具都可以通过两种方式调用：菜单适合探索，命令行选项适合脚本与批处理。

Interactive menu交互菜单

gpumdkit.sh
 ---------------------- GPUMD ------------------------
 1) Format Conversion          2) Sample Structures
 3) Workflow                   4) Calculators
 5) Analyzer                   6) Visualization
 7) Utilities                  8) Help
 0) Exit
 ------------>>
 Input the function number:

Type a module number, then a function number such as 203. At file prompts Tab completes names.

输入模块编号，再输入功能编号（如 203）。在文件名提示处可用 Tab 补全。

Command line命令行

gpumdkit.sh -<option> [args...]
gpumdkit.sh -out2xyz ./scf_results
gpumdkit.sh -min_dist_pbc dump.xyz
gpumdkit.sh -plt train
gpumdkit.sh -calc msd dump.xyz Li 10

gpumdkit.sh -plt -h        # list plot types
gpumdkit.sh -range -h      # help of one option

-h lists everything; gpumdkit.sh -<option> -h shows the arguments of Python-backed options.

-h 列出全部选项；对基于 Python 的选项，gpumdkit.sh -<option> -h 会显示其参数说明。

How to read the examples示例约定

Notation写法Meaning含义Example示例
<required>A value you must provide; do not type the angle brackets.必须提供的值，不要输入尖括号。<output.xyz> → model.xyz
[optional]May be omitted; the script then uses its documented default.可省略，省略后脚本使用文档中的默认值。[max_corr_steps]
...One or more values.一个或多个值。<element...>
!
Time parameters such as dt_fs must match how your trajectory was written; GPUMDkit does not read them from the MD input file. Example values like Li 1 only show the argument format, they are not defaults.
dt_fs 等时间参数必须与你自己的轨迹写出方式一致，GPUMDkit 不会从 MD 输入文件中读取。Li 1 之类的示例值只用于说明参数格式，并非默认值。
