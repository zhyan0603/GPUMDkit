训练集需要的是多样性，而不只是数量。GPUMDkit 提供多种方式挑选和清理候选结构。在交互菜单中进入 gpumdkit.sh → 2，并按提示输入文件名。

Clean before you select挑选之前先清理

Check distances first, then filter. -min_dist_pbc only reports; the -filter_* commands remove structures and write a new file.

先检查距离，再做过滤。-min_dist_pbc 只做报告；-filter_* 系列会删除结构并写出新文件。

from MD frames to a candidate set
gpumdkit.sh -min_dist_pbc dump.xyz                        # report only
gpumdkit.sh -filter_dist_pbc dump.xyz <min_distance>      # writes filtered_dump.xyz
gpumdkit.sh -filter_box filtered_dump.xyz <edge_limit>    # optional, writes filtered_by_box.xyz
gpumdkit.sh                                               # 2) Sample Structures -> 203
