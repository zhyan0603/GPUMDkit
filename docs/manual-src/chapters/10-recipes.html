Typical sequences, from raw output to a result you can use.

从原始输出到可用结果的典型命令序列。

Detailed pages详细页面Active learning workflow主动学习工作流Diffusion plots扩散绘图

Three end-to-end examples. Steps marked you run it use other software; GPUMDkit prepares around them.

三个端到端示例。标有 由你运行 的步骤使用其他软件，GPUMDkit 负责前后衔接。

Convert the finished calculations转换已完成的计算

gpumdkit.sh -out2xyz <scf_results_directory>   # writes NEPdataset/train.xyz

Check energies and forces检查能量与力

gpumdkit.sh -range NEPdataset/train.xyz energy
gpumdkit.sh -range NEPdataset/train.xyz force

Check distances and composition检查间距与成分

gpumdkit.sh -min_dist_pbc NEPdataset/train.xyz
gpumdkit.sh -analyze_comp NEPdataset/train.xyz

Optional: split into training and test sets可选：划分训练集与测试集

gpumdkit.sh   # 2) Sample Structures -> 206

Prepare MD sampling directories准备 MD 采样目录

gpumdkit.sh   # 3) Workflow -> 302

Run GPUMD in each directory在每个目录中运行 GPUMD

Filter the trajectory过滤轨迹

gpumdkit.sh -min_dist_pbc dump.xyz
gpumdkit.sh -filter_dist_pbc dump.xyz <minimum_distance>

Select diverse structures (FPS)用 FPS 挑选多样性结构

gpumdkit.sh   # 2) Sample Structures -> 203

Prepare DFT single points准备 DFT 单点计算

gpumdkit.sh   # 3) Workflow -> 301 -> VASP or CP2K

Run DFT with your own settings用你自己的参数运行 DFT

Convert and check the new labels转换并检查新标签

gpumdkit.sh -out2xyz <scf_results_directory>
gpumdkit.sh -range <new_reference.xyz> force

Merge the data and retrain the NEP合并数据并重新训练 NEP

Inspect the new model查看新模型

gpumdkit.sh -plt train
gpumdkit.sh -plt prediction

Run GPUMD with compute_msd运行带 compute_msd 的 GPUMD

Look at the MSD查看 MSD

gpumdkit.sh -plt msd

Check convergence (needs save_every in compute_msd)检查收敛性（compute_msd 需设置 save_every）

gpumdkit.sh -plt msd_conv

Estimate the ionic conductivity估算离子电导率

gpumdkit.sh -calc ionic-cond <element> <charge>

Repeat at several temperatures在多个温度下重复

Plot the Arrhenius fit绘制 Arrhenius 拟合

gpumdkit.sh -plt D/sigma     # see the plot pages for the input layout

Scientific choices — thresholds, DFT settings, sampling temperature, acceptance criteria — are yours to make. The recipes show the commands, not recommended values.
阈值、DFT 参数、采样温度、验收标准等科学选择需要由你自己决定。这些流程只展示命令，不提供推荐数值。
