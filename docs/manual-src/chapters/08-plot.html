Every plot is one option: gpumdkit.sh -plt <type>. Run it in the directory that holds the GPUMD or NEP outputs. Several plots accept save to write an image instead of opening a window; gpumdkit.sh -plt -h lists all types and arguments.

每种图只需一个选项：gpumdkit.sh -plt <type>。请在存放 GPUMD 或 NEP 输出的目录中运行。部分绘图支持 save 参数，直接保存图片而不弹出窗口；gpumdkit.sh -plt -h 可列出全部类型及参数。

Click a figure to enlarge it and copy the command. More examples are in the gallery.
