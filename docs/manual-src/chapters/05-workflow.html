Workflows工作流

Prepare batches of DFT and MD jobs without writing the glue scripts yourself.

批量准备 DFT 与 MD 任务，不用自己再写胶水脚本。

Detailed pages详细页面Workflow scripts工作流脚本

Workflow scripts prepare directories, inputs and links. They never submit calculations: you review the generated files and run DFT, GPUMD or LAMMPS yourself.

工作流脚本只负责准备目录、输入文件和链接，不会提交任何计算：请检查生成的文件，并自行运行 DFT、GPUMD 或 LAMMPS。

301

SCF batchSCF 批量预处理

Create DFT single-point directories for many structures (VASP or CP2K).

为大量结构生成 DFT 单点计算目录（VASP 或 CP2K）。

302

MD batch (GPUMD)MD 采样批量预处理（GPUMD）

Create one GPUMD sampling directory per structure, linked to shared inputs.

为每个结构生成 GPUMD 采样目录，并链接共享输入文件。

303

MD batch (LAMMPS)MD 采样批量预处理（LAMMPS）

The same, for LAMMPS-based sampling.

同上，用于基于 LAMMPS 的采样。

What 301 builds (VASP)301 会生成什么（VASP）

gpumdkit.sh → 3 → 301 → VASP
.
├── struct_fp/      # the structures to label
├── fp/             # put your INCAR, POTCAR and KPOINTS here
│   └── ...            # one calculation directory per structure
└── presub.sh      # generated helper script — review before use

Before submitting, check the number of structures, atom and species order, cells, DFT inputs and the job script. For CP2K (301 → 2) GPUMDkit asks for an extxyz file, an input template and a directory prefix.

提交之前，请检查结构数量、原子与元素顺序、晶胞、DFT 输入以及作业脚本。CP2K 分支（301 → 2）会询问 extxyz 文件、输入模板和目录前缀。

!
Function 302 only creates directories and symlinks. Afterwards put nep.txt and one run_<index>.in per structure into the generated md/ directory, and check each directory points to the right files. GPUMD appends to some outputs, so rerun in a clean directory or archive old results.
302 只创建目录和软链接。之后请把 nep.txt 以及每个结构对应的 run_<index>.in 放入生成的 md/ 目录，并确认每个目录指向正确的文件。GPUMD 会向部分输出追加内容，请在干净目录中重跑或先归档旧结果。
