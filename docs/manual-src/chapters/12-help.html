Troubleshooting常见问题

gpumdkit.sh is not found.提示找不到 gpumdkit.sh。

Activate the Conda environment (conda activate gpumdkit). For a source install, open a new shell so the PATH written by install.sh is loaded.

请先激活 Conda 环境（conda activate gpumdkit）。源码安装时，请新开一个 shell，让 install.sh 写入的 PATH 生效。

A package shows MISS in -doctor.-doctor 显示某个包 MISS。

Optional packages are only needed for the features that use them. Install one when a command asks for it, for example pip install neptrain calorine.

可选包只在对应功能中才需要。命令提示缺少时再安装即可，例如 pip install neptrain calorine。

A converter overwrote my file.转换器覆盖了我的文件。

Converters write into the current directory. Work in a fresh directory and keep the source data separate.

转换器会写入当前目录。请在新目录中操作，并把源数据单独保存。

The conductivity looks wrong.电导率结果看起来不对。

Check that element matches the species in msd.out and model.xyz, that the first four columns of msd.out are time and MSD_x/y/z, and that the MSD curve is converged.

请确认 element 与 msd.out、model.xyz 中的物种一致，msd.out 前四列为时间与 MSD_x/y/z，且 MSD 曲线已经收敛。

How do I get help on one option?如何查看某个选项的帮助？

gpumdkit.sh -h lists all options; gpumdkit.sh -plt -h lists plot types; gpumdkit.sh -<option> -h shows the arguments of Python-backed options.

gpumdkit.sh -h 列出全部选项；gpumdkit.sh -plt -h 列出绘图类型；gpumdkit.sh -<option> -h 显示基于 Python 的选项的参数。
