Web console

Your runs, in any browser

Start gpumdkit.sh -server in a work directory and follow remote jobs from your laptop.

  • Live loss curves and NEP training progress, refreshed automatically.
  • MD monitor for neighbor.out, run.in step progress, speed and ETA.
  • One-click plot actions that match the files in each folder.
  • Sandboxed file browser with create, upload and download.

Get started

Up and running in a minute

Install with Conda (recommended) or from source, then type gpumdkit.sh.

OPTION A · RECOMMENDED

Conda

conda create -n gpumdkit -c gpumdkit -c conda-forge gpumdkit
conda activate gpumdkit
# optional extras for some features
pip install neptrain calorine

Update later with conda update -c gpumdkit -c conda-forge gpumdkit.

OPTION B · FROM SOURCE

Git

git clone https://github.com/zhyan0603/GPUMDkit.git
cd GPUMDkit
source ./install.sh
# ready to go
gpumdkit.sh

Pull the latest version of your branch with gpumdkit.sh -update.
