Getting started快速入门

Install, verify, and run your first command in about two minutes.

两分钟内完成安装、验证，并跑通第一条命令。

Detailed pages详细页面Quick start快速入门

1Install安装

$conda create -n gpumdkit -c gpumdkit -c conda-forge gpumdkit

Conda is the recommended route: it installs GPUMDkit with its standard dependencies, with no repository clone or environment variables. Then conda activate gpumdkit. Choose source if you want to read or modify the code — the installer writes GPUMDkit_path and PATH to your ~/.zshrc or ~/.bashrc after backing it up.

推荐使用 Conda：它会连同标准依赖一起安装 GPUMDkit，无需克隆仓库或配置环境变量，安装后执行 conda activate gpumdkit 即可。如果想阅读或修改代码，请选择 source：安装脚本会先备份 ~/.zshrc 或 ~/.bashrc，再写入 GPUMDkit_path 和 PATH。

2Check that it works检查安装

gpumdkit.sh -h        # list every option
gpumdkit.sh -doctor   # check the Python environment
✓
MISS for an optional package is not an error. -doctor reports common and optional packages; install an optional one only when you need the feature that uses it, e.g. pip install neptrain calorine.
可选包显示 MISS 并不是错误。-doctor 会报告常用和可选的 Python 包；只有在需要对应功能时才安装，例如 pip install neptrain calorine。

Format conversion格式转换

Bring DFT and MD outputs into extxyz, and reshape extxyz files for training.

把 DFT 与 MD 的输出转换为 extxyz，并整理成适合训练的形式。

Detailed pages详细页面Format conversion格式转换

GPUMDkit converts between the formats used in computational materials science and the extended XYZ (extxyz) files used by GPUMD and NEP. Run it in the directory where you want the results: most converters write into the current directory, even when the input is elsewhere.

GPUMDkit 在计算材料学常用格式与 GPUMD/NEP 使用的扩展 XYZ（extxyz）之间转换。请在希望保存结果的目录中运行：多数转换器即使输入文件在别处，也会把结果写到当前目录。

Anatomy of an extxyz fileextxyz 文件长什么样

train.xyz — illustrative values, 2 atoms示意数值，2 个原子
2
Lattice="5.43 0.0 0.0 0.0 5.43 0.0 0.0 0.0 5.43" Properties=species:S:1:pos:R:3:forces:R:3 energy=-10.52 virial="-0.21 0.0 0.0 0.0 -0.21 0.0 0.0 0.0 -0.21" pbc="T T T"
Si  0.00  0.00  0.00   0.012 -0.020  0.003
Si  1.36  1.36  1.36  -0.012  0.020 -0.003
  1. Atom count of this frame; a file stacks many frames.
  2. Lattice: nine numbers (three cell vectors, row-major, in Å).
  3. Properties declares the atom columns: species, position, force.
  4. Frame labels: total energy and virial (eV) from the reference calculation.
  5. One line per atom: element, position (Å), force (eV/Å).
  1. 原子数：当前帧的原子个数，一个文件可以串联很多帧。
  2. Lattice：9 个数（三个晶格矢量，按行排列，单位 Å）。
  3. Properties 声明每个原子行包含哪些列：元素、坐标、力。
  4. 帧级标签：参考计算得到的总能量和维里（eV）。
  5. 每个原子一行：元素、坐标（Å）、力（eV/Å）。

Example: ionic conductivity示例：离子电导率

!

在自己的浏览器里查看训练与 MD 运行，并一键出图。

Detailed pages详细页面Remote web console远程网页控制台

gpumdkit.sh -server starts a browser-based console rooted at the directory you launched it from. The browser shows files that stay on the remote machine, so you can inspect runs, trigger plots and do small file operations without copying the whole project.

gpumdkit.sh -server 会以启动时所在的目录为根，开启一个基于浏览器的控制台。浏览器显示的文件始终留在远程机器上，因此无需拷贝整个项目，就能查看计算、触发绘图并做简单的文件操作。

Connect in three steps三步连接

Start the server on the remote host在远程主机上启动服务

remote terminal — keep it open
ssh <user>@<host>
conda activate gpumdkit
cd /path/to/working-directory
gpumdkit.sh -server

Open an SSH tunnel from your workstation在本地工作站建立 SSH 隧道

local terminal — keep it running
ssh -N -L 8888:127.0.0.1:8888 <user>@<host>

Open it in your local browser在本地浏览器中打开

address
http://127.0.0.1:8888

If port 8888 is busy locally, forward another one (-L 8890:127.0.0.1:8888, then open port 8890). If it is busy on the remote host, start the server on another port (gpumdkit.sh -server 9000) and forward that one.

如果本地 8888 端口被占用，可转发到其他端口（-L 8890:127.0.0.1:8888，然后访问 8890）。如果远程 8888 被占用，则用其他端口启动服务（gpumdkit.sh -server 9000）并转发该端口。

Server options and safety服务选项与安全

syntax
gpumdkit.sh -server [port] [-b <address>] [-pw <password>]
gpumdkit.sh -server -h
Option选项Default默认值Meaning含义
port8888Port of the web serverWeb 服务端口
-b <address>127.0.0.1Network address to listen on监听的网络地址
-pw <password>optional on loopback回环地址下可选Login password; required for any other address登录密码；监听其他地址时必须设置
!
Keep the default loopback address and use an SSH tunnel. Binding to another address such as 0.0.0.0 requires a password and the server does not use HTTPS. The terminal drawer is not restricted to the browsing root. Keep passwords out of shared scripts and shell history.
请保持默认的回环地址，并通过 SSH 隧道访问。绑定到 0.0.0.0 等其他地址时必须设置密码，且服务不使用 HTTPS。终端抽屉不受浏览根目录限制。请勿把密码写进共享脚本或 shell 历史。
Symptom现象Check排查
Browser cannot connect浏览器无法连接Both the remote server and the local tunnel must still be running, with matching ports.远程服务和本地隧道必须仍在运行，且端口一致。
The wrong files appear显示的文件不对The root is the directory where -server started. Restart it from the intended directory.根目录就是启动 -server 的目录，请在目标目录中重新启动。
Plot actions fail绘图操作失败Start the server from the environment that has GPUMDkit and the plot dependencies.请在装有 GPUMDkit 及绘图依赖的环境中启动服务。
Progress does not change进度不变It only changes when the output files receive new records; it is not a scheduler monitor.只有输出文件写入新记录时才会变化，它并非作业调度监控。

Troubleshooting常见问题

gpumdkit.sh is not found.提示找不到 gpumdkit.sh。

Activate the Conda environment (conda activate gpumdkit). For a source install, open a new shell so the PATH written by install.sh is loaded.

请先激活 Conda 环境（conda activate gpumdkit）。源码安装时，请新开一个 shell，让 install.sh 写入的 PATH 生效。

A package shows MISS in -doctor.-doctor 显示某个包 MISS。

Optional packages are only needed for the features that use them. Install one when a command asks for it, for example pip install neptrain calorine.

可选包只在对应功能中才需要。命令提示缺少时再安装即可，例如 pip install neptrain calorine。

A converter overwrote my file.转换器覆盖了我的文件。

Converters write into the current directory. Work in a fresh directory and keep the source data separate.

转换器会写入当前目录。请在新目录中操作，并把源数据单独保存。

The conductivity looks wrong.电导率结果看起来不对。

Check that element matches the species in msd.out and model.xyz, that the first four columns of msd.out are time and MSD_x/y/z, and that the MSD curve is converged.

请确认 element 与 msd.out、model.xyz 中的物种一致，msd.out 前四列为时间与 MSD_x/y/z，且 MSD 曲线已经收敛。

How do I get help on one option?如何查看某个选项的帮助？

gpumdkit.sh -h lists all options; gpumdkit.sh -plt -h lists plot types; gpumdkit.sh -<option> -h shows the arguments of Python-backed options.

gpumdkit.sh -h 列出全部选项；gpumdkit.sh -plt -h 列出绘图类型；gpumdkit.sh -<option> -h 显示基于 Python 的选项的参数。
