脚本位置： Scripts/calculators/

功能概览

计算器模块大致可以分为四类：

  • 轨迹性质： 从 GPUMD 或 extxyz 轨迹计算 MSD、离子电导率等时间相关性质，并从 extxyz 轨迹计算 X 射线衍射；
  • 声子性质： 使用原胞、NEP 模型和 QPOINTS 路径计算力常数和声子谱；
  • NEP 辅助计算： 使用 NEP 模型预测能量/力/应力、提取描述符、计算 DOAS、进行 NEB 或结构优化；
  • 极性材料分析： 为钙钛矿和极性材料构建近邻列表、计算局域位移、平均结构、八面体倾转和局域极化。

如果你还不熟悉某个脚本，建议先用交互模式查看输入提示；如果已经知道参数，可以直接使用 gpumdkit.sh -calc ... 调用支持 CLI 的计算器。XRD 和声子计算均只保留交互模式。

离子电导率

calc_ion_conductivity.py 从 msd.out 计算离子扩散系数和离子电导率。

bash
gpumdkit.sh -calc ionic-cond Li 1
参数 表示什么 运行前检查
element 要分析 MSD 的移动物种 元素符号应与 msd.out 和 model.xyz 中代表的物种一致。
charge Nernst–Einstein 换算所用的电荷大小 应按自己的体系给出电荷定义。实现中使用其平方，因此只改变正负号不会改变报告的电导率。

示例 Li 1 仅用于说明参数格式，并不是所有体系的默认选择。当前实现使用 MSD 数据中间的 40–80% 区间拟合。解读扩散系数或电导率前，应先检查 MSD 曲线及其收敛情况。

计算器读取第 1–4 列的时间和 MSD_x/y/z。element 参数用于计数离子， 不选择 MSD 列；all_groups 输出需先提取目标组的时间和 MSD 列。电荷参数为 以元电荷为单位的整数。结果为 Nernst–Einstein 电导率，不包含离子间位移关联。

交互模式选择 401，会看到：

text
Input <element> <charge> (eg. Li 1)
------------>>

常用输入文件：

文件 作用
msd.out 必需，MSD 数据
thermo.out 可选，自动读取温度
model.xyz 可选，自动读取体积和离子数
run.in 可选，识别扩胞信息

如果缺少自动识别所需文件，脚本会交互式询问温度、体积和离子数。

手动模式的提示类似：

text

Please provide the following values:
--------------------------->
Enter average temperature (in K):
Enter system volume (in A^3):
Enter number of ions:

从轨迹计算 MSD

calc_msd.py 可以直接从 extxyz 轨迹中计算指定元素的 MSD。

bash
gpumdkit.sh -calc msd dump.xyz Li 10
gpumdkit.sh -calc msd dump.xyz Li 10 5000

使用固定晶胞、原子顺序一致的轨迹，并确保 pos 字段存储已核验的展开坐标。 脚本读取 pos 和首帧晶胞，不读取独立的 unwrapped_position 属性。自动坐标 判断不足以验证折回轨迹；按轴解包裹也不适用于一般倾斜或变化晶胞。 命令覆盖当前目录的 msd.out。

交互模式选择 412，会看到：

text
Input <extxyz_file> <element_symbol> <dt_fs> [max_corr_steps]
  Optional argument: max_corr_steps (default: frame number)
Example: dump.xyz Li 10
------------>>

参数含义：

参数 含义
dump.xyz 输入轨迹
Li 目标扩散元素
10 帧间隔，单位 fs
5000 可选，最大相关步数

max_corr_steps 限制参与相关计算的最大时间滞后。省略时，脚本使用已有帧数。它会改变计算窗口，应根据自己轨迹的长度和采样间隔选择，而不是照搬其他体系的数值。

输出：

  • msd.out

calc_msd.py 写入的 msd.out 恰好包含四个数值列：Time(ps)、MSD_x、 MSD_y 和 MSD_z。该输出可以使用 -plt msd 绘图。

相比之下，GPUMD 原生的 compute_msd 写入的是另一种 msd.out。只选择一个 分组时，它包含七列：时间、MSD_x/y/z 和 SDC_x/y/z；-plt sdc 与 -plt msd_sdc 要求这种格式。使用 all_groups 或多个分组时，GPUMD 会追加 其他分组的数据，因此不能假定每个 msd.out 都有七列。GPUMD 的独立命令 compute_sdc 写入 sdc.out，该文件供 -plt vac 使用，不是 -plt sdc 或 -plt msd_sdc 的输入。

随后可绘图：

bash
gpumdkit.sh -plt msd

X 射线衍射（XRD）

calc_xrd.py 从 extxyz 轨迹计算并平均与 LAMMPS 兼容的 XRD 强度。该功能 只保留交互式入口，不提供 CLI 参数接口。

在菜单中选择 4) Calculators，再选择 413) Calc XRD from extxyz trajectory。Python 交互页面依次询问：

text
Input extended XYZ trajectory
Output XRD file
X-ray wavelength (Angstrom)
2theta range (degrees; min max)
Number of bins in this 2theta range
Elements to include (all or comma-separated) [all]
CPU workers (0 means automatic) [0]

bins 始终覆盖选定的 2theta 区间。例如，选择 10 60 和 500 个 bins， 表示将 10 到 60 度均匀划分为 500 个区间，不再单独设置输出 bin 范围。

元素选择输入 all 可包含全部原子，也可以输入 Li 或 Li,Cl 等元素符号； 元素匹配不区分大小写。默认使用输入轨迹中的 Lattice 和 pbc、标准 LAMMPS 散射因子以及 Lorentz-polarization 因子。当前支持正交晶胞；非正交 晶胞会被拒绝，因为该计算器使用当前 LAMMPS 兼容的 reciprocal mesh 约定。

输出文件包含元数据表头，随后是四列数据：

列 含义
Bin 从 1 开始的直方图 bin 序号
Coord 选定 2theta 区间内 bin 的中心，单位为度
Count 平均 XRD 强度
Count/Total 用选定区间总强度归一化后的强度

轨迹较长时，可以用多个 CPU worker 加速，结果不受影响。

声子谱

calc_phonon.py 使用 NEP 模型计算力常数，并沿 QPOINTS 中定义的路径计算 声子谱。该功能只通过交互模式使用：

text
gpumdkit.sh -> 4) Calculators -> 414) Calc phonon band structure

Python 页面会依次询问：

text
Primitive cell structure [PRIMCELL.vasp]
NEP model [nep.txt]
QPOINTS file [QPOINTS]
Supercell dimensions [1 1 1]
Displacement distance [0.015]
Output phonon file [phonon_NEP.dat]

QPOINTS 必须使用 line-mode 的起点/终点成对格式。脚本从第二行读取每段 Q 点数，生成的输出行随后由 plt_phonon.py 和 plt_phonon_comp.py 使用。 运行前请安装 phonopy：

bash
pip install phonopy

NEP 预测性质

calc_properties_with_nep.py 使用训练好的 NEP 模型计算能量、力和应力。

依赖： calorine

bash
pip install calorine
bash
gpumdkit.sh -calc nep structures.xyz predictions.xyz nep.txt

提示： 预测前可以清理 extxyz 元数据：

bash
gpumdkit.sh -clean_xyz train.xyz clean_train.xyz

NEP 预测输出文件

prediction.py 使用 Calorine 的 CPUNEP 计算每个 frame，并写出 NEP parity 工具使用的四类预测文件。输出后缀根据输入文件名自动确定：例如输入 test.xyz 时，当前目录会生成 energy_test.out、force_test.out、 stress_test.out 和 virial_test.out。

bash
# 单核计算（默认）
gpumdkit.sh -prediction train.xyz nep.txt

# 使用八个独立 CPU worker
gpumdkit.sh -prediction train.xyz nep.txt 8

每行先写预测值，再写目标值。能量单位为 eV/atom，力为 eV/Angstrom，应力为 GPa，virial 为 eV/atom。应力和 virial 张量使用 NEP 顺序 xx yy zz xy yz xz，并遵循 NEP 相同的符号约定：在这些文件中 stress = virial / volume， 受压为正。输入 extxyz 中 stress= 字段的符号相反（受拉为正），因此与 NEP 一样按 virial = -stress * volume 换算。如果某个 frame 只有 stress 或 virial 中的一种标签， 程序按此关系及相应单位换算自动推导另一种； 只有两种标签都缺失时，两个目标列才写入 NEP 约定的 -1e6 哨兵值。energy 和 force 标签必须存在。计算过程中会显示 tqdm 进度条。

该命令需要 calorine、ase 和 tqdm：

bash
pip install ase calorine tqdm

DPA 预测输出文件

prediction_dpa.py 使用 DeepMD DPA 模型计算带标签的 extended XYZ 训练集， 并将 energy_train.out、force_train.out、virial_train.out 和 stress_train.out 写入当前目录。

bash
gpumdkit.sh -prediction_dpa train.xyz model.ckpt.pt

输出格式遵循 NEP 训练 prediction 约定：每行先写预测值，再写目标值。能量单位为 eV/atom，力为 eV/Angstrom，应力为 GPa，virial 为 eV/atom。该命令需要 deepmd-kit 和 numpy。

NEP 描述符

bash
gpumdkit.sh -calc des train.xyz descriptors.npy nep.txt Li

用途包括：

  • 用 PCA/UMAP 可视化局域环境；
  • 比较训练集和候选结构；
  • 判断新数据是否扩展了描述符空间。

绘图：

bash
gpumdkit.sh -plt des pca descriptors.npy
gpumdkit.sh -plt des umap descriptors.npy

DOAS

calc_doas.py 用于计算 Wang et al. 提出的原子态密度（density of atomistic states，DOAS）。

bash
gpumdkit.sh -calc doas structures.xyz nep.txt doas.out
gpumdkit.sh -plt doas doas.out Li

脚本会：

  1. 读取所有结构；
  2. 使用 NEP 进行结构优化；
  3. 提取每个原子的能量；
  4. 按元素分组输出；
  5. 将分组结果写入输出文件（可用 -plt doas 可视化）。

对于很大的体系，如果主要目的是获得优化后的结构和原子能量分布，直接在 GPUMD 中完成最小化和原子能量输出通常会更高效。

NEB 和结构优化

NEB：

bash
gpumdkit.sh -calc neb initial.xyz final.xyz 9 nep.txt

这会使用 NEP 模型运行包含 9 个中间构型（image）的 NEB 计算。运行过程中脚本会询问原子固定方式：

  • none：不固定原子；
  • index：按原子索引（编号）固定；
  • element：固定某一种元素的所有原子；
  • position：固定坐标范围内的原子。

结构优化（通过 calorine）：

依赖： calorine

bash
pip install calorine
bash
gpumdkit.sh -calc minimize POSCAR nep.txt 0.01 1000

参数说明：

参数 含义
POSCAR 输入结构，POSCAR/CONTCAR 或 extxyz
nep.txt NEP 模型
0.01 可选的力收敛阈值（eV/Ang）
1000 可选的最大优化步数

输出包括：

  • minimize.xyz
  • minimize.log

使用 OVITO 计算 RDF

rdf_calculator_ovito.py 使用 OVITO 的分析工具计算径向分布函数。

依赖： OVITO

bash
pip install ovito

输入文件： 结构文件（单帧或轨迹）

bash
python "${GPUMDkit_path}/Scripts/calculators/rdf_calculator_ovito.py" trajectory.xyz 6.0 400

参数：

参数 含义
trajectory.xyz 输入结构文件
6.0 RDF 计算的最大距离（Å）
400 直方图的分箱数

输出： rdf.txt。

条件允许时，建议直接在 GPUMD 运行中使用 compute_rdf 计算 RDF；它输出的 rdf.out 可以用 gpumdkit.sh -plt rdf 绘制，该命令不读取 rdf.txt。

铁电和极性材料工具

选项 406–410 面向钙钛矿和极性材料分析，常用于从 MD 轨迹中提取局域结构信息，然后进一步分析相变、畴结构或极化纹理。

这些脚本在本页只做快速索引，因为它们通常需要组合使用。推荐阅读专题教程中的完整工作流和参数说明：极性材料分析。

菜单 CLI 子命令 作用 详细说明
406 gpumdkit.sh -calc nlist ... 构建指定中心原子和近邻原子之间的近邻列表 极性材料分析
407 gpumdkit.sh -calc disp ... 根据轨迹和近邻列表计算局域位移 极性材料分析
408 gpumdkit.sh -calc avg-struct ... 从轨迹中计算平均结构 极性材料分析
409 gpumdkit.sh -calc oct-tilt ... 计算八面体倾转角 极性材料分析
410 gpumdkit.sh -calc pol-abo3 ... 根据 Born 有效电荷估算 ABO3 局域极化 极性材料分析

部分脚本需要安装 ferrodispcalc：

bash
pip3 install git+https://github.com/MoseyQAQ/ferrodispcalc.git

一个典型顺序是先用 nlist 建立近邻列表，再用该近邻列表计算位移、倾转或极化。对于平均结构，可以直接从轨迹出发，用长度容差控制哪些帧参与平均。
