安装

使用 Conda（推荐）

bash
conda create -n gpumdkit -c gpumdkit -c conda-forge gpumdkit
conda activate gpumdkit

这会安装 GPUMDkit 及其标准依赖，不需要克隆仓库，也不需要配置环境变量。

从源码安装

如果你想阅读或修改源码，可以这样安装：

bash
git clone https://github.com/zhyan0603/GPUMDkit.git
cd GPUMDkit
source ./install.sh

安装脚本会把 GPUMDkit_path 和 PATH 写入配置文件并在当前 shell 中生效：$SHELL 为 zsh 时写入 ~/.zshrc，否则写入 ~/.bashrc。修改前会先备份该文件；如果已经配置过 GPUMDkit 路径，会先询问是否替换。

检查安装

bash
gpumdkit.sh -h
gpumdkit.sh -doctor

-h 列出全部选项；-doctor 检查 Python 环境，并报告常用包和可选包的状态。可选包显示 MISS 并不是错误，只有用到相应功能时才需要安装。

第一个练习：转换一个 POSCAR

请在新目录中运行，以免覆盖已有文件：

bash
mkdir gpumdkit-first-check && cd gpumdkit-first-check
cat > POSCAR << 'EOF'
Si
1.0
0 2.715 2.715
2.715 0 2.715
2.715 2.715 0
Si
1
direct
0 0 0
EOF
gpumdkit.sh -pos2exyz POSCAR model.xyz
head model.xyz

model.xyz 中应包含一个 Si 原子和晶格信息。

extxyz（扩展 XYZ）是 NEP 使用的训练数据格式：第一行是原子数，第二行是晶格和结构级属性，之后每行记录一个原子的元素、坐标和原子级属性。

两种使用方式

交互模式

运行 gpumdkit.sh，按编号选择模块，每个模块都有自己的子菜单。在输入文件名时，可以按 Tab 补全，用方向键移动光标修改。

命令行模式

直接给出选项和位置参数，也可以写进脚本：

bash
gpumdkit.sh -<option> [args...]

gpumdkit.sh -h 列出全部选项，gpumdkit.sh -plt -h 列出绘图类型。对于由 Python 实现的选项，gpumdkit.sh -<option> -h 会显示该命令的参数说明。

如何阅读示例命令

写法 含义 示例
<required> 必须提供的值，输入时不要带尖括号。 <output.xyz> → model.xyz
[optional] 可以省略，脚本会使用文档中说明的默认行为。 [max_corr_steps]
... 可以跟一个或多个值。 <element...>

dt_fs 等时间参数要与你写出轨迹时的设置一致，GPUMDkit 不会从 MD 输入文件中读取。

可选包与 Agent 技能

部分功能需要额外的包：

bash
pip install neptrain calorine

GPUMDkit 还自带中英文 Agent 技能。运行下面的命令，可以查看它们的安装位置，以及如何添加到你的 Agent 客户端：

bash
gpumdkit.sh -skill
